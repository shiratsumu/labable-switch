# labable-switch (Firmware)

このプロジェクトの機能を用いて、ESP32に接続した現実の物理スイッチのオンオフを感知し、「入室」「退出」をブラウザ上で発行されたリンクと連動して送信します。

スイッチは `ESP32 - スイッチ - LED` のような構成になります。
- スイッチをON（入室）にすると、ESP32が指定先のURLを叩き、物理LEDが点灯する。
- スイッチをOFF（退室）にすると、物理LEDが消灯し、ESP32がURLを叩いて退室通知を送る。

ブラウザのUIで生成したURL（暗号化されたWebhook情報やチャンネル名が含まれたもの）をそのままESP32に設定することで、物理スイッチからの通知を特定のSlackチャンネルに送信することができます。
※HTTPS通信（本番サーバー）にも対応しています。

## 必要なハードウェア・回路の組み方
1. **ESP32** (メインマイコン)
2. **スイッチ**: ESP32の `GPIO 4` ピンと `GND` の間に接続します。内蔵プルアップを使用するため外部抵抗は不要です。（※テスト時は14番ピン等に変更可能）
3. **LED**: ESP32の `GPIO 5` ピンに接続します。直列に電流制限抵抗（330Ω程度）を挟み、LEDのマイナス側を `GND` につなぎます。

## 初期設定
初期設定として、Wi-Fiの認証情報、**ブラウザで発行されたURL**、通知に使う名前をデバイスに記憶させる必要があります。

1. `firmware/labable_switch/secrets.example.h` を同じフォルダにコピーし、`secrets.h` という名前で保存します。
2. `getStart.html` 等で生成・コピーした自分の入退室用URLを確保します。
   （例： `http://example.com/?ch=your-channel&posturl=ENC_WEBHOOK`）
3. `secrets.h` をテキストエディタで開き、以下の内容をご自身の環境に合わせて書き換えます。
   - `ssid` / `password`: 接続するWi-Fiルーターの情報
   - `generatedUrl`: 先ほどコピーした **ブラウザで生成されたURL** をそのまま貼り付けます。
   - `userName`: 通知で表示したいあなたの名前（例: `"saka"`）
   - `iconEmoji`: Slackに表示されるアイコン（例: `":beginner:"`）

※ プログラム内で `generatedUrl` を解析し、自動的にサーバーAPI（`slack.php`）のパスと送信に必要なチャンネル名やWebhookキーを抽出します。
また、起動時にNTP（ネットワーク時刻）同期を行うため、正確な時刻で入室時間が記録されます。

## 実機確認方法の手順（テスト）
1. 回路（ESP32・スイッチ・LED）の結線を確実に行い、ESP32をPCにUSB接続します。
2. Arduino IDEなどで、`labable_switch.ino` をコンパイルしてマイコンへプログラムを書き込みます。
3. **シリアルモニタを開いてネットワーク接続を確認する**
   - ボーレートを `115200` に設定し、ESP32の電源を入れ直します。
   - `Connected to WiFi!` および `Time synchronized` が表示された後、URLの解析結果が正しく表示されるか確認します。
4. **スイッチをONにする（入室のアクション）**
   - 物理スイッチをON方向に倒すと、シリアルモニタに `Switch is ON - User Entered` と出力されます。
   - その後、**LEDが点灯** します。
   - 実際のSlackに連携され、該当チャンネルに入室の通知が通っているかを確認します。
5. **スイッチをOFFにする（退室のアクション）**
   - 物理スイッチをOFFにします。
   - シリアルモニタに `Switch is OFF - User Exited` と出力され、退室のリクエストが送信されます。
   - **LEDが消灯** します。
   - 実際のSlackで退室が通知されることを確認します。

## ローカル環境でのテスト（開発時）の注意事項
ローカル（自分のPC内）で `php` サーバーを立ち上げてESP32からテスト通信を行う場合、以下の点に注意してください。

1. **PHPサーバーの起動方法**
   メインプロジェクトのREADMEにあるような `php -S localhost:8000` で起動すると、外部機器（ESP32）からのアクセスが拒否されてしまいます。
   ESP32（同じWi-Fiネットワーク）からアクセスできるように、以下のように `0.0.0.0` を指定して起動してください。
   ```bash
   php -S 0.0.0.0:8000
   ```

2. **ESP32に設定する URL について**
   PCのブラウザで開いている時点では `http://localhost:8000/?...` となっていますが、これをそのままESP32に設定すると「ESP32自身」を探してしまい通信に失敗します。
   `secrets.h` の `generatedUrl` に貼り付ける際は、`localhost` の部分をPCの実際のローカルIPアドレスに置き換えてください。
   - 変更前： `http://localhost:8000/?ch=...`
   - 変更後： `http://192.168.x.x:8000/?ch=...`

3. **SlackのWebhook設定（名前とアイコンの上書き）**
   新しく作成したSlackアプリ（Webhook）を利用してテストする場合、そのままでは「Demo App」などのアプリ名が強制表示され、プログラムからの `userName` や `iconEmoji` の変更が無視されてしまいます。
   Slack上にご自身の名前とアイコンを正しく表示させるには、Slack APIの設定画面（OAuth & Permissions）で **`chat:write.customize`** の権限（スコープ）を付与し、ワークスペースにアプリを再インストールしておく必要があります。
   （※以前から使われている古い形式のWebhook（Legacy Webhooks）を利用する環境であれば、特に設定しなくても上書きが可能です）
